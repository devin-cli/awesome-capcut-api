# Awesome CapCut API

*Unofficial community list for CapCut API. Not affiliated with CapCut. All trademarks belong to their owners.*

A curated list of the pages that matter when you are researching the CapCut API: the official AI API page, the CapCut products and AI features it sits beside, the template page that confusingly ranks for the same query, and the automation alternatives the sources name for the things CapCut's API does not do (composing scenes, subtitles, rendering MP4s). Every link below appears in the three top-ranking pages for this query.

## Official resources

- [CapCut AI API](https://www.capcut.com/explore/ai-api) - the official API page; per JSON2Video it covers AI features such as background removal and upscaling, not full editing automation.
- [CapCut](https://www.capcut.com/) - product homepage.
- [CapCut Desktop](https://www.capcut.com/tools/desktop-video-editor) - the desktop editor.
- [CapCut Online](https://www.capcut.com/creative-suite) - the browser-based creative suite.
- [CapCut Mobile](https://www.capcut.com/tools/capcut-apk-latest-version-android-download) - the mobile app download page.
- [CapCut x Codex plugin](https://www.capcut.com/tools/capcut-x-codex) - editor plugin listed under Products.
- [Simple API documentation template](https://www.capcut.com/explore/simple-api-documentation-template/7497640535021996048) - a design template, not developer docs; listed so nobody mistakes it for the API reference.

## Getting started

- Read the AI API page first and note what it exposes; the sources give no endpoint or auth details, so the page itself is the reference.
- [CapCut AI tools](https://www.capcut.com/tools/ai-tools) - index of the consumer AI features, useful for checking which ones the API does or does not cover.
- [JSON2Video: CapCut API alternative](https://json2video.com/how-to/capcut-api/) - the clearest written statement of what CapCut's API covers and where it stops.

## Alternatives

- [Synexa](https://synexa.ai?utm_source=github&utm_medium=ugc&utm_campaign=awesome-capcut-api&utm_content=readme-top&utm_term=tier-r) - generation rather than editing: one REST endpoint and a Python SDK for FLUX, video and audio models, pay per run.
- [JSON2Video](https://json2video.com/) - the alternative the sources name for full video automation: scenes, voiceover, subtitles, transitions and cloud rendering from a JSON description; see its [docs](https://json2video.com/docs/v2/) and [templates](https://json2video.com/templates/).
- [Creatomate alternative](https://json2video.com/how-to/creatomate-alternative/), [Remotion alternative](https://json2video.com/how-to/remotion-alternative/), [Shotstack alternative](https://json2video.com/how-to/shotstack-alternative/), [Bannerbear alternative](https://json2video.com/how-to/bannerbear-alternative/) - JSON2Video's comparison pages, which name four other video and image automation products.
